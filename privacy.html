Privacy Policy

Effective date: August 14, 2026 · Last updated: September 13, 2026

This policy explains what Quaestio ("the bot", "we", "us") collects, why it collects it, and the rights you have over your data. It applies to anyone who uses the bot in a Discord server.

1. The short version

Quaestio is designed to be private by default. By default you use the shared bot (no setup); server owners may instead point it at their own hardware, and anyone may lend compute to the community pool.

We make no commitment to keep the service running, accurate, or available, and we accept no responsibility for data loss, deleted content, account actions (warns, kicks, bans, mutes), or decisions made from AI output. Everything is provided as-is — see the Terms.

The bot does not sell, rent, or share your data with anyone. It does not use cookies, trackers, or advertising.

2. What we collect

  • Discord identifiers — server (guild) IDs and user IDs, used to attribute XP, warnings, tags, and server settings to the right place.
  • Leveling activity — a counter of messages per user for the XP/level system.
  • Content you explicitly ask the bot to store — tags and warning reasons that server moderators create.
  • Server configuration — settings you choose, such as the welcome channel or level-reward roles.
  • AI prompts — your prompt is processed by a local AI model on real hardware (the shared host, the server owner's box, or a participating community host — see Security & Architecture). It is not sent to commercial third-party AI providers by the bot itself. Assume a pool node can technically read prompts routed to it.
  • Conversation memory and learned facts — recent channel turns and short facts you state about yourself (e.g. likes), used to keep chats coherent.
  • Birthdays — month/day you save with /birthday set.

3. What we do NOT collect

  • Full message history or chat logs beyond the short conversation memory above.
  • Email addresses, phone numbers, or real names.
  • IP addresses (beyond what Discord itself processes).
  • Any data sold, rented, or shared with advertisers or analytics companies.

4. How data is stored and protected

Data is stored in a local SQLite database on the server where the bot runs. Access is limited to the server operator. Reasonable security practices are used, including dedicated non-login service accounts, restricted file permissions, and local-only access to the AI model.

5. Who has access

Because Quaestio is self-hosted, the server operator (the person who runs the bot) has access to the data. No centralized company collects it. Discord Inc. processes data according to its own policies.

6. Retention and deletion

Data is kept for as long as the bot is running and needed. If you want your data removed, contact the server operator directly. Operators can clear a user's XP and warnings with the built-in commands, or delete the database entirely.

7. Children's privacy

Quaestio is not directed at children under 13. If you believe a child's data has been handled improperly, contact the server operator of the server where the bot is used.

8. Changes to this policy

We may update this policy as the bot evolves. Material changes will be reflected here with an updated date.

9. Contact

For privacy questions, contact the operator of the server where you use the bot — the person who hosts and runs it. Because Quaestio is self-hosted, that operator is the data controller for your data.
