# Quaestio changelog

## 2026-09-12
- Pull-based community pool: contributors call out, no inbound/Tailnet needed.
- `quaestio pool-serve` one-command serving; browser WebGPU hosting on the pool page.
- Contributor perks: priority routing, share-scaled request limits, gold badge, anonymous leaderboard.
- AI personalities via Ollama system role; default model qwen2.5:1.5b.
- Flood-guard abuse protection instead of quotas (5/20 per min, more for contributors).
- Single typing indicator; progress + failure logging wired to monitor emails.

## 2026-09-11
- Fast failover routing, pool health tracking, encrypted pool storage.
- Admin dashboard: batched settings, host pool management, preset tiles.
- One-line macOS/Linux/Windows installers with interactive TUI.
