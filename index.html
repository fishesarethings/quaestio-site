Questions, answered.

Is it really free? What’s the catch?

Really free. The core — all 41 commands — has no paywall and no premium-gated features. Quaestio runs on the host’s own hardware, so there’s nothing to meter. Donations are welcome but never required.

Can the AI run on a different computer, like Windows?

Yes. Quaestio talks to any Ollama over the network — run Ollama on a spare PC (Windows, Linux or macOS), open its port, and set the endpoint in /ai endpoint (admins) or OLLAMA_BASE_URL in .env. The model host can be as weak as you like; the bot handles one chat at a time and shares the brain fairly across servers.

Can I self-host Quaestio itself on Windows?

Yes — the bot, the AI and the admin panel all run on Windows. Open PowerShell and paste powershell -ExecutionPolicy Bypass -Command "irm https://quaestio.online/bot/install.ps1 | iex" to install everything, then start it with run-quaestio.bat. It runs on startup and stores settings encrypted on your machine. Manage it from any PowerShell or Command Prompt with quaestio (menu), quaestio help, quaestio settings or quaestio uninstall. The web panel is optional; the README has the full Windows walkthrough.

Do we have to @ the bot for every message?

No. After the first @ (or /ask), turn on Keep chatting without @ in the web panel and the bot stays in the conversation — members just keep typing. It goes quiet again after a few minutes of silence, or right away if someone says go away.

What are the personalities and characters?

Personalties tint how Quaestio talks — Friendly, Wise sage, Sarcastic wit, Pirate, Professional or None — while characters change who it pretends to be, like Jeff from Mars or a Wholesome grandma. Admins pick both in the web panel, or write their own custom ones and edit or delete them anytime.

Is there a web settings panel?

Yes. Run /panel (or open your server’s panel URL) and sign in with Discord as an admin. From there you control the AI box, model, memory, quotas, personalities, characters, welcome messages, birthdays, level roles and moderation limits — all stored on your server.

Can my server run its own model instead?

Yes. Admins pick their own Ollama box in the web panel (endpoint + model) — choose My own as the AI source. You can also contribute your box to the shared pool so other servers can use it. Contributions are anonymous — endpoints and models are encrypted at rest and only a random node ID is ever shown — so nobody can piece together who contributes. Only server admins can change these settings.

How does the AI work, and where does my data go?

The AI is a small model running on the server owner’s machine. Your prompts are processed locally and are not sent to third-party AI providers by the bot. Nothing is sold, tracked or shared — see the Privacy Policy.

Why does the AI reply one at a time and type slowly?

By design. A local model is fast but focused, so Quaestio handles one conversation at a time and types replies out like a human would. It keeps responses coherent and the server calm — if it’s busy, /ask politely asks you to wait a moment.

Can Quaestio run on a weak VPS?

Yes. The bot itself is light. For the AI, a 1–4 GB model runs fine on a small VPS or a spare PC; if your box can’t host a model, you can point Quaestio at a compatible model endpoint elsewhere.
