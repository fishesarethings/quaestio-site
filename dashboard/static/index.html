Self-host & contribute

Run Quaestio on your own machine

One command installs the bot + a friendly manager on macOS, Linux or Windows. No admin needed. Pick yours:

curl -fsSL https://quaestio.online/bot/install.sh | bash
Requires Python 3.10+ · creates ~/quaestio · asks for your bot token once.

🧭 The manager (CLI)

After installing, `quaestio` is a command on your PATH. Just type it to open the friendly menu — update, settings, uninstall, contribute, local web panel:

quaestio

…or one-liners: quaestio help, status, settings, contribute, update, uninstall.

⚡ Contribute to the pool

Running home server AI? Opt in and pick how much of your box to lend. Contributions are anonymous — a random node ID, endpoint + model encrypted at rest — so nobody can piece together who contributes.

quaestio contribute

🔒 Privacy first

Your endpoint and model are never shown to anyone. The panel only ever displays a random ID and totals, never identities.

🧹 Nothing left behind

quaestio uninstall stops the bot, removes the service, the keyfile and ~/quaestio — and the installers remove the quaestio command too. Most apps can't say that.
