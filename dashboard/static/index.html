Self-host on Windows

The bot and this panel both run on Windows. Open PowerShell and paste:

powershell -ExecutionPolicy Bypass -Command "irm https://quaestio.online/bot/install.ps1 | iex"
Then start with: run-quaestio.bat

Want the web panel on Windows too?

pip install -r dashboard/requirements.txt
set DISCORD_CLIENT_ID=...
set DISCORD_CLIENT_SECRET=...
uvicorn app:app --host 127.0.0.1 --port 8900
See README → “Admin web panel” for full setup.
