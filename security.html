Security & Architecture

Plain-language description of how Quaestio works, what each part can see, and how to check our claims. Source: GitHub. Contact: info@quaestio.online.

Hosting modes

  • Shared host (default). You invite Quaestio's bot to Discord. No Discord bot token, no setup. AI runs on community hardware via the pool.
  • Your own box. Point your server at your Ollama in the admin panel. Same bot, your compute.
  • Community pool. Anyone lends spare AI compute with quaestio pool-serve or the browser host. No Discord token involved anywhere.

What data moves where

  • Discord → bot: message text the bot is asked about, plus display names. The bot never asks for passwords.
  • Bot → model host: the prompt (conversation + question), sampling settings, and a stop list. Display names travel as Name[1234] speaker tags.
  • What a pool node sees: the prompt text it is asked to complete. Assume a node operator can technically read prompts routed to them — that is why routing is random, nodes are anonymous, and failures park bad nodes automatically.
  • What the router stores: anonymous node IDs, encrypted endpoints/models, served counts, health timestamps. No chat content is stored by the pool; job rows are deleted after delivery (stale claims requeue after 120s, rows older than an hour are reaped).
  • What Discord admins see: their own servers' settings, memory, and leaderboards via Discord OAuth. Never anyone else's data.

Encryption, precisely

  • In transit: TLS (HTTPS/WSS) for site, panel, broker, and Discord. Tailnet traffic is WireGuard-encrypted.
  • At rest: secrets, endpoints, and models in the database are Fernet-encrypted (AES-CBC + HMAC); the key file is 0600.
  • Not claimed: true end-to-end encryption of prompts. A model host must decrypt a prompt to run it. We do not use the term “end-to-end encrypted”.

Pool: not mining, no money

Lending compute earns priority routing, higher request limits, and a contributor badge. There is no cryptocurrency, no cash payout, no resale, and no financial return. Only approved model families run; substituted models are refused. Stop anytime: quaestio → leave the pool, uninstall, or just close the tab.

Installer behavior

Review source first: install.sh · install.ps1. It creates ~/quaestio (venv, bot code, .env 0600, keyfile), installs Python deps + Ollama + one model, and optionally registers a pool node. It never asks for a Discord bot token. Contacts: raw.githubusercontent.com, ollama.com, quaestio.online, and the pool broker. Uninstall: quaestio uninstall (or delete ~/quaestio).
